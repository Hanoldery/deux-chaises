# Historique des versions

Le numéro de version a trois parties, par exemple 1.2.3 :

- **majeure** (le 1) : une règle change ;
- **mineure** (le 2) : une partie s'ajoute ;
- **correctif** (le 3) : une correction.

## 1.0.0 (23 octobre 2026)

Première version publique.

- Le guide : pourquoi ça marche (3 études), les 7 règles, avant, pendant (1 h 30 en 5 temps), si la tension monte, le débrief en 3 questions.
- Le kit de l'organisateur, utilisable sans ordinateur : lieu, affiche, questionnaire, paires à la main, accueil, déroulé minute par minute, rôle de l'animateur, après.
- Les cartons à imprimer.
- Des images dans le README : bannière, déroulé en 5 temps, les 7 règles, les 3 chiffres, aperçus des cartons.
- La correspondance avec les 10 règles de Faut qu'on parle.
