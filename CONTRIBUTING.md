# Contribuer

Pas besoin de savoir coder pour améliorer la méthode. Tout est du texte.

## Raconter, proposer, traduire : ouvrez un ticket

Sur GitHub, onglet **Issues**, bouton **New issue**, puis choisissez :

- **Retour d'atelier** : vous avez organisé une rencontre ; dites-nous ce qui a marché, ce qui a coincé.
- **Proposition** : une règle, une étape, une formulation à changer.
- **Traduction** : vous voulez traduire la méthode dans une autre langue.

Pas de compte GitHub ? Écrivez à contact@pierre.gd : nous ouvrirons le ticket pour vous.

## Modifier un texte directement

Les deux textes source sont [guide.md](guide.md) (la méthode) et [organiser.md](organiser.md) (le kit de l'organisateur).

1. Ouvrez le fichier sur GitHub et cliquez sur l'icône crayon.
2. Modifiez le texte. Gardez la forme : les titres `##`, les listes, le gras `**…**`, le tableau du déroulé.
3. En bas, décrivez votre changement en une phrase, puis **Propose changes**.

Les cartons à imprimer (`cartons/`), les images (`images/`) et le README sont produits à partir de ces deux fichiers : ne les modifiez pas, ils seront remis à jour. Pour changer ce que dit une image, changez le texte : l'image suivra. Une fois votre proposition acceptée, elle passe telle quelle sur le site Deux chaises, sans être retapée.

## Ce qui entre doit pouvoir ressortir

Tout ce que vous proposez est publié sous la même licence que le reste ([CC BY-SA 4.0](LICENSE)) : chacun pourra le reprendre et l'adapter, comme vous avez pu reprendre la méthode. N'apportez donc que des textes que vous avez écrits vous-même ou qui sont déjà sous une licence compatible. Ne recopiez pas de passages d'autres guides, même pour une ligne.

## Chaque chiffre a sa source

Un chiffre, une étude, un « ça marche » : donnez le lien vers l'étude et dites ce que vous y avez lu (pays, nombre de personnes, durée de l'effet). Sans source, nous ne pouvons pas le publier.

## Comment on décide

Chaque proposition est lue. Nous répondons en suivant le [code de conduite](CODE_OF_CONDUCT.md), qui reprend nos 7 règles de table. Si votre proposition est retenue, vous êtes remercié dans [CONTRIBUTORS.md](CONTRIBUTORS.md), avec votre accord seulement. Le numéro de version change selon ce qui bouge (voir [CHANGELOG.md](CHANGELOG.md)).

Vous avez adapté la méthode chez vous ? Ajoutez votre version à [ADAPTATIONS.md](ADAPTATIONS.md).
