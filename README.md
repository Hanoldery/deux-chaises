# Deux chaises : la méthode

Deux chaises est une méthode libre pour organiser une heure et demie de conversation en tête-à-tête entre deux personnes qui ne pensent pas pareil, dans une bibliothèque, une association ou un tiers-lieu. C'est un dialogue : on fait connaissance et on cherche à comprendre comment l'autre en est arrivé là. Ce n'est pas un débat : il n'y a rien à gagner, et personne n'a à changer d'avis.

## Utiliser

Tout tient dans ce dossier et fonctionne sans ordinateur : imprimez, posez sur les tables, lisez à voix haute.

## Adapter (forker)

Copiez ce dossier (sur GitHub : bouton **Fork**) et changez ce que vous voulez : les mots, la durée, le nombre de tours, vos propres règles, une autre langue. Gardez si possible les trois piliers : faire connaissance avant de parler du désaccord, écouter sans interrompre, finir par le débrief.

Deux conditions : créditer et garder la même licence. Crédit à recopier : « D'après Deux chaises, REX club (CC BY-SA 4.0). Inspiré de Faut qu'on parle (guide de conversation 2026). » Puis ajoutez votre version dans [ADAPTATIONS.md](ADAPTATIONS.md), pour que d'autres la trouvent.

## Proposer une amélioration

Pas besoin de savoir coder : racontez votre atelier, proposez un changement ou une traduction en ouvrant un ticket, ou modifiez directement [guide.md](guide.md) et [organiser.md](organiser.md) sur GitHub (icône crayon). Tout est expliqué dans [CONTRIBUTING.md](CONTRIBUTING.md). Chaque chiffre ajouté doit avoir sa source. Les échanges suivent nos règles de table : [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
